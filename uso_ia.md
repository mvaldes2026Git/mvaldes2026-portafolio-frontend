## Asistencia de IA
En la estructuración de este proyecto se utilizó IA Generativa como asistente de refactorización y depuración de código.

1. **Refactorización Semántica:** Se utilizó para limpiar la estructura HTML previa (un mockup de cabañas) y adaptarla a un Portafolio Personal estricto de 3 secciones (Sobre Mí, Proyectos, Contacto), eliminando elementos innecesarios (imágenes, videos, JS complejo) para cumplir 100% con la pauta.
2. **Validación de Breakpoints:** Se le consultó la mejor estrategia para acomodar el formulario de contacto en formato de grilla (CSS Grid) para el punto de quiebre de Tablet (`≥768px`).
3. **Auditoría de Accesibilidad:** La IA sugirió mantener la clase `.sr-only` y `:focus-visible` para garantizar la navegabilidad por teclado.

Toda la estructura fue testeada manualmente en navegador para comprobar responsividad y foco.
